# Dépendances de l'ATELIER (Kleos) — distinctes de `requirements.txt`, qui reste
# la liste minimale des builders du site statique (markdown seul).
#
# Elles n'y figuraient pas alors qu'elles sont indispensables : mesuré le
# 2026-08-04, playwright 1.58.0 et python-docx 1.2.0 étaient installés sur le poste
# mais déclarés nulle part. Une image construite depuis `requirements.txt` seul
# aurait échoué au premier rendu — et la dérive ne se serait vue qu'en production.
# playwright est ÉPINGLÉ AU CLOU, pas borné par une plage — et la version doit
# rester égale au tag de l'image de base dans Dockerfile.kleos.
#
# `>=1.58,<2` semblait prudent ; il a installé 1.62.0 sur une base v1.58.0-noble,
# et le premier rendu PDF est mort sur :
#   Executable doesn't exist at /ms-playwright/chromium_headless_shell-1234/...
# L'invariant n'est pas « au moins 1.58 » mais « exactement la version dont les
# navigateurs sont cuits dans l'image ». Une plage semver exprime une compatibilité
# d'API ; ici le paquet pip n'est qu'un pilote vers un chromium livré à part.
playwright==1.58.0
python-docx>=1.2,<2
